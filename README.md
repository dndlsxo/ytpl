# YTPL — 유튜브 재생목록 최고 음질 다운로더 (Android)

유튜브 재생목록 링크 하나로 전체 곡을 **재인코딩 없는 원음** 또는 MP3 320kbps로 받아
`음악(Music)/YTPL/재생목록 이름/` 에 트랙 번호·앨범명·정사각형 커버까지 넣어 저장하는 안드로이드 앱입니다.
Termux 같은 별도 앱 없이 단독으로 동작합니다.

## 구조

| 구성 | 역할 |
|---|---|
| yt-dlp (앱 실행 시 자동 최신화) | 재생목록 목록 추출, 스트림 주소 해독, 다운로드 |
| Python 3.11 · QuickJS (내장) | yt-dlp 실행 환경 / 유튜브 플레이어 JS 서명 해독 |
| FFmpeg (내장) | 오디오 추출·변환, 태그·커버 삽입 |
| 포그라운드 서비스 | 화면을 꺼도 끝까지 다운로드, 알림에 진행률 표시 |
| MediaStore 등록 | 완성된 곡을 음악 폴더에 저장 → 음악 앱에 바로 표시 |

엔진은 [youtubedl-android](https://github.com/yausername/youtubedl-android) 0.18.1 라이브러리를 사용합니다.

## 저장 형식

- **원음 그대로 (기본, 최고 음질)**: 유튜브가 보관한 최고 음질 오디오(보통 Opus ~160kbps)를 변환 없이 저장. `.opus`
- **MP3 320kbps**: 호환성 최우선. 원본을 다시 압축하므로 원본보다 좋아지지는 않음.
- **M4A (AAC)**: 아이폰·차량용. AAC 원본이 있으면 변환 없이 저장.

## APK 빌드 (PC 없이 가능)

1. GitHub에서 **새 저장소**(Private 권장)를 만들고 이 폴더 내용을 그대로 올립니다.
   - 휴대폰이면: 저장소 → *Add file → Upload files* 에서 압축을 푼 파일·폴더를 업로드
   - 점(.)으로 시작하는 `.github` 폴더는 업로드에서 빠지는 경우가 많습니다. 빠졌다면
     *Add file → Create new file* 에서 이름을 `.github/workflows/build.yml` 로 적고 내용을 붙여넣으세요.
2. 올리면 **Actions** 탭에서 자동으로 빌드가 시작됩니다 (약 5~10분).
3. 끝나면 저장소의 **Releases**에 APK가 올라옵니다.
   - 대부분의 휴대폰: `YTPL-arm64-v8a.apk`
   - 모르겠으면: `YTPL-universal.apk` (용량 큼, 모든 기기)
4. 휴대폰에서 APK를 받아 설치 (출처를 알 수 없는 앱 설치 허용 필요)

Android Studio에서 열어 `Build → Build APK(s)` 로 빌드해도 됩니다.

### 서명 키
`app/ytpl-release.jks` 가 포함되어 있어 매번 같은 키로 서명되므로 새 버전을 덮어 설치할 수 있습니다.
저장소를 **Public으로 만들 경우** 키가 공개되니, 새 키를 만들어 Secrets
(`YTPL_KEYSTORE_BASE64`, `YTPL_KEYSTORE_PASSWORD`, `YTPL_KEY_ALIAS`, `YTPL_KEY_PASSWORD`)로 넣는 것을 권장합니다.

## 사용법

- 앱에 링크 붙여넣기 → 형식 선택 → **다운로드 시작**
- 또는 유튜브 앱에서 **공유 → YTPL**
- 중간에 끊겨도 같은 링크로 다시 시작하면 **받은 곡은 건너뛰고** 나머지만 받습니다.
- 다운로드 중에 다른 링크를 넣으면 대기열에 추가됩니다.

## 문제 해결

- **"Sign in to confirm you're not a bot" / 403** → 앱 아래쪽 *yt-dlp 업데이트* 후 잠시 뒤 재시도
- **음악 폴더에서 지운 곡을 다시 받고 싶음** → *받은 기록 초기화*
- **믹스(RD…) 목록**은 끝이 없어서 앞 50곡만 받습니다.
- 좋아요/나중에 볼 동영상 같은 **로그인 전용 목록은 지원하지 않습니다.**

## 주의

유튜브 약관은 앱 밖으로 내려받는 것을 원칙적으로 허용하지 않습니다.
저작권이 있는 음원은 개인 감상 용도로만 사용하고 공유·재배포하지 마세요.
